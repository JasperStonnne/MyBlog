## 友链

一些常看的站点、朋友的角落，以及能把人带回真实工程现场的入口。

### 朋友与博客

- [boweny's Blog](https://b0weny-qwq.github.io/Blog/)  
  工程、嵌入式、Agent 与个人成长记录。这个站也是本博客切换到 Stack 主题时的参考对象。

- [Linux.do](https://linux.do/)  
  技术社区，适合看工具、AI、开发环境和工程实践相关讨论。

### 我在别处

- [GitHub / JasperStonnne](https://github.com/JasperStonnne)  
  代码、实验项目和博客源码都会逐渐放在这里。

- [Linux.do / jaspersao](https://linux.do/u/jaspersao/summary)  
  一些更日常的技术讨论和社区动态。

### 建站相关

- [Hugo](https://gohugo.io/)  
  这个博客使用的静态站点生成器。

- [Hugo Theme Stack](https://github.com/CaiJimmy/hugo-theme-stack)  
  当前博客使用的主题，适合偏阅读和归档的个人博客。

- [Giscus](https://giscus.app/zh-CN)  
  当前博客使用的评论系统，基于 GitHub Discussions。
